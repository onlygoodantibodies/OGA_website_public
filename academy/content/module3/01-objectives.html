The OGA database has grown well beyond a list of antibodies. It now covers five applications, says how strongly the data supports each antibody in each one, and feeds a set of tools that bring the same results into the papers you read and the antibodies you buy. This module walks through all of it.

By the end of this module you will be able to:

  • Find an antibody by gene, catalogue number or RRID, and nominate a gene that is not there yet
  • Read a gene page: the report, the filters, the example row and the figure for each application
  • Tell apart the four results — Supportive, Limited support, Not supportive and Not tested — and say what each does and does not mean
  • Know what OGA's immunohistochemistry results are, and where tissue staining is shown
  • Choose the right tool for the job: the browser extension, the AI connector, the Selection Tool, the Validation Record, or the Data Portal & API
  • Cite an antibody and a report correctly

Estimated time: 20–25 minutes. Keep onlygoodantibodies.co.uk open in another tab and try each step as you read it.
