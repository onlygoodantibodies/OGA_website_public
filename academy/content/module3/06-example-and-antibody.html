Key message: compare every antibody with the example at the top, one application at a time.

The first row on every gene page is Example — High-performing Antibody. It is a drawing, not a real antibody: it shows what ideal data looks like in each application the gene was tested in. It stays pinned at the top while you scroll, so you can compare each real figure with it.

Each antibody below it has, on the left:

  • The catalogue number, as the supplier prints it
  • RRID: the Research Resource Identifier to cite it by (more on this at the end of the module)
  • Supplier: a link to the product page, for the current datasheet, price and availability, and the applications the supplier claims
  • Host (e.g. rabbit, mouse), clonality (monoclonal, polyclonal, recombinant) and the Clone ID where there is one
  • Characterisation data supports: the applications where OGA's result is Supportive

To the right is one figure per application: the wild-type and knockout result cropped from the report. Click a figure to enlarge it. Under each figure are the words for the result, and a figure with supportive data has a green border.
