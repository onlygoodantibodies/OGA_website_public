The figure cropper used to publish straight to the website — one press, no second look — because a `PublicationImage` row *is* publication. It writes here instead now, and this is the only screen in the app that turns a crop into a public figure. So it is built the way the delete panel is built: say what is about to happen, in the words a person would use, with the number on the button being the number that was consented to. Two things it must never do, both learned elsewhere in this repo. It must not tell the reader to reload — a release redraws its own list. And it must not publish a set that has grown since the list was drawn: the count goes back with the press and the server refuses a mismatch (`services/review.py::release`). {% endcomment %} {% block content %}

Review queue

Figures waiting to be published

Everything the figure cropper makes waits here. No gene page lists a figure from this page until it is released, and the data portal shows it only to the supplier whose reagent it is. The crop file itself is already at its public address, though, so anyone given its link can open it — a figure held back here is unlisted, not locked away. Releasing is what publishes: the crop goes onto the gene's public page and OGA's recommendation is applied to the antibody at the same moment. The one exception is a crop that replaces a published figure (the card says so): the cropper writes it to the file the gene page is showing, so that page can show it already.

Each figure carries the whole judgement, in two halves. Under the image: what the figure shows — for a western blot, does it detect the target and is it selective; for IF, how selective; for IP, does it enrich; for IHC, how selective, judged by eye from the HAP1 pellet figure — staining in wild-type cells and none in the knockout is selective, and in a mosaic pellet stained and unstained cells share one field. Beside the name: the recommended / not recommended button, which starts from the antibody's own recommendation (or, for a figure re-cropped while it waits here, from what was set on this card) — the cropper sets none. The line at the foot of each card is what the public page will print once it is released, built from both. Click a figure to see it full size.

The recommendation waits here until release. The outcome answers are stored on the antibody straight away, the same as on Judge outcomes — so on a figure that replaces a published one they reach that public page now, and the card says so.

Have a finished panel to swap in for one antibody? Replace a figure finds the antibody and queues the new image here.
