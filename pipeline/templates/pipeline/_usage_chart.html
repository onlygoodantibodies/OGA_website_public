{% comment %} One counter's last N days as a column chart. Included with: {% include "pipeline/_usage_chart.html" with series=api.series busiest=api.busiest_day unit="requests" %} `series` is `[{date, n}, …]` oldest first with **zeros already filled in** by `impact._daily_series`, and `busiest` is its tallest bar, computed in the view because `widthratio` is the only arithmetic a template has and it cannot find a maximum. Setting a bar's height from its own count instead draws every busy day identically once it passes the track — the bug the Overview chart shipped with. Drawn as a fixed 64px track filled bottom-up, one column per day, so thirty days fit on a line. `min-height` is on the **non-zero** bars only: a zero day must be an empty track, or a chart of nothing draws a floor of activity that did not happen. The count is on the title attribute *and* the busiest day is written out underneath — a `title` is not a label, and this file's whole job is to be read at a glance. {% endcomment %}
