{% comment %}The pipeline's stylesheet, and the one place that decides where it comes from. base.html and login.html both include this; neither names a source. Preferred is the file this site builds and serves itself (`bin/build_css.sh` → `pipeline/static/pipeline/tailwind.css`). Second is Tailwind's Play CDN, which builds the CSS in the browser on every page load — Tailwind's own development build, and what the app ran on until now. Which one is in use is `pipeline/styling.py`, and `pipeline.W003` says at deploy time if production ended up on the CDN. Everything under `.no-tailwind` is the fallback for the stylesheet that never arrives, whichever of the two it was. Without it there is no `.hidden` — and `.hidden` is how every dropdown, modal, delete confirmation and upload panel in this app is kept shut, 250 times over across these templates and board.js, so they all render open and stacked down the page. The nav is white text on `bg-ycharos-800`, so it disappears entirely. Plain is survivable; that is not. It cannot reach a page whose stylesheet loaded: the class is added only by the two failure paths at the bottom. It covers blocked, 404 and down — not slow.
