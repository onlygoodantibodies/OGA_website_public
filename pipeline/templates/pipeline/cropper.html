4 · Seed grid {% comment %}An IHC figure is many rows of the same panels (TP53: nine rows of five), so typing the count once beats typing it nine times — and the copy control below makes one row's fitted edges every row's, in one press, instead of dragging the same lines nine times.{% endcomment %}
Then drag to fit. Orange = edges (top/bottom span the figure; each row's left & right are independent, so an inset/centred row brackets just its panels). Blue = row dividers. Green = column splits (double-click a row to add one, Alt-click any green/blue line to delete). A row of N panels needs N−1 green lines between its two orange edges.
Fit one row's orange edges and green lines, then copy them to the rest. Panels already assigned stay assigned in rows that keep their number of panels.
