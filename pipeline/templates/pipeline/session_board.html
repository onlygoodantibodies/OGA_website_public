{% comment %}The sheet this panel is about, inside the panel that asks for it. Every other upload surface in the app offers its own artefact — the three boards' pop-outs hand you the blank template — and this one said "download the sheet" with nothing to click, its Download button sitting outside and above the panel it had just been told to open. Deliberately **not** the blank `sessions` template that the Add panel on this same board carries: that one is for `bulk_sessions`, which *creates*. This endpoint matches on `session_id` + `result_id` and only ever edits, so the only file it can act on is one the app stamped with those ids — the board's own export. A blank template posted here reads as "0 rows", with no error, because its sheet is not one of the four procedure tabs `session_io.parse_upload` looks in. Two surfaces on one board, two artefacts. And it carries the grid's filters, because it is the same function the Download button runs — a second implementation is the bug that once handed a filtered board the whole dataset.{% endcomment %}
