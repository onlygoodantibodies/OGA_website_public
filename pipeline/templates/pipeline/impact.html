Impact

What the site has recorded people doing

Every figure here is something the application wrote down because a person did it — a request served, a certificate issued, a plan recorded. Assembled from four apps that each kept their own count, so a report or a grant can quote one page instead of four admin screens.

{% comment %} Said first, and deliberately not in small print at the bottom. This page has no visitor numbers in it and never will — those live in Cloudflare — and a reader who takes these totals for traffic will read them as far too small and conclude the site is unused. Naming the gap is the difference between a narrow number and a wrong one. {% endcomment %}

This is not traffic. Django records no page views, visitors or referrers — those are in Cloudflare, which is a different account and a different question. What is below is the narrower and harder number: someone finished a lesson, built a plan, pulled the API. Read it as reach and engagement, never as how many people saw the site.

Days in is the number to quote. The portal reconnects itself whenever the tab is reloaded, so connects counts reloads, and a key shared inside one company counts as one organisation however many people use it. Dates, not times. The counter keeps one row per organisation per day so that its size is set by who holds a key rather than by how hard anyone pulls — which buys the dates and gives up the clock. There is no “signed in at 14:03” here. Last API call is any request, sign-in or not. Far ahead of last in means a script that still syncs for an organisation whose people have stopped opening the portal — which neither number shows on its own. {% if portal.refused %} {{ portal.refused }} sign-in attempt{{ portal.refused|pluralize }} carried no usable key — missing, unknown, or belonging to a key that has been switched off. A refused attempt cannot be attributed, by design: the row is keyed on a caller the request failed to identify. So it is a total and never a name, and it is here because “somebody is trying with a key that no longer works” is a support question that would otherwise be invisible. {% endif %}
