Downloads & uploads

Export the whole pipeline dataset (including unpublished data), edit it in Excel or with a chat assistant — for example, fill in missing F1000/Zenodo DOIs and antibody product URLs across many genes — then upload it back. Uploading only adds and updates: a blank cell never clears anything, rows you remove from the file are left untouched, and changing an already-filled value asks you to confirm first. Members only; nothing here is public.

Download the dataset

Excel is one workbook with a sheet per family plus a Legend; JSON is the same data as a gene tree. Pick a preset or open a family and tick the fields you want — every family you tick something in gets a sheet, and its locked id and key columns come with it so the upload lands each row on the right record.

Enter gene symbols in any case — kif5a, KIF5A and Kif5a all match the same gene. Separate several with commas. Leave blank to download everything.

Upload changes

Upload the edited .json or .xlsx (or a single-sheet .csv) — the same file you downloaded, with gaps filled. The importer reads columns by header, so whatever subset you exported lands correctly. We'll show you exactly what would change before anything is written. Editable: antibodies, reports, and — by id — targets, cell lines, samples, assignments, reagent requests, cell culture events and inventory (storage locations). Creating new records stays on their dedicated pages, and people columns are export-only reference (never written back).
