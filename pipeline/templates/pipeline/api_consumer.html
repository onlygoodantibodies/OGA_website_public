{% comment %} Named, not buried. Every silence below is one a reader would otherwise fill with a conclusion about the partner: a page with nothing on it reads as an organisation doing nothing, when it can equally be an organisation whose key was switched off, or one reading the catalogue on an endpoint nothing counts. {% endcomment %}

What this page cannot tell you. The counter keeps one row per organisation per endpoint per day, which is what stops it growing with traffic — and it buys the dates and gives up the clock. There is no time of day here.

  • A call refused by the rate limit is not counted at all, so a partner hammering the API is understated here and everybody else is exact.
  • A call carrying a dead or wrong key is counted as keyless and cannot be attributed, by design — so if their key were switched off, their attempts would not appear on this page.
  • Reading the catalogue or the schema ({{ uncounted|join:", " }}) passes through no counter, so silence there is not evidence.
  • The counter records which endpoint, never which gene or antibody was asked for — the URL name is stored precisely so a query string cannot multiply the rows.
  • Reporting a problem is counted above like any other call, but what they reported is not: it is sent as an email and no row is written, so the substance of a complaint cannot be recovered from here.
