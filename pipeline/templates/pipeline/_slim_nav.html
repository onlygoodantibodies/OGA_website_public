Styled inline, with no class on anything. That is not laziness: this bar renders on a page that loads Bootstrap (the account card and its form are Bootstrap, via crispy) and on a page that loads neither Bootstrap nor Tailwind (the cropper). An inline style is the only thing that means the same on both, and it cannot be reached by a page's own stylesheet — which is exactly how the real nav lost every link on Set recommendations, to one `.hidden { display:none !important }`. The colours and proportions are base.html's: #064c83 is `bg-ycharos-800`, 4rem is `h-16`, and the links are its `text-sm`. It should read as the same bar with fewer things on it, because that is what it is. Add a destination here and add it to base.html's two Browse menus as well — there are three lists now and a link in one of them is a link on a third of the app's pages. {% endcomment %}
