{% comment %} Self-contained hamburger-menu toggle for the site header. Included by the shared header partials (core/header.html, academy/header.html) and any standalone page that renders its own .hamburger markup, so the mobile menu works even on pages that don't load core/script.js. Idempotent: uses the same `hamburger.dataset.bound` guard as core/script.js, so if both run on the same page the menu is only wired up once. {% endcomment %}
