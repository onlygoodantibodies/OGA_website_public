How to embed OGA validation data on your product pages

Each card below previews your antibody's independent characterisation data exactly as it will appear when embedded. The Copy button copies an iframe showing all tested applications in one card.

To embed data for a single application only, use the WB, IP, ICC-IF, or FC buttons below each card. These copy an iframe that shows only that application's data.

Paste any of these iframe snippets into your product page HTML. The cards update automatically when new data is added. For CMS help, contact onlygoodantibodies@gmail.com.
