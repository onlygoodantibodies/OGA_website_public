{% load static %} {% comment %} Slim bar that sits directly under the site header: a plain-language way back to the gene list, plus the search box. Why it exists: on a gene page (/antibodies/SNCA/) the only route back to the gene list was clicking the logo, which nobody does because nothing says it is a link, and there was no way to jump to a different gene without going home first. Included from core/header.html; skipped on the homepage, which has its own hero search over the gene boxes already in the DOM. The markup and the styling are this file's; the *behaviour* is core/static/core/oga_search.js, shared with the homepage box — two boxes that answer differently give a reader no way to tell which one is broken. The suggestion list is moved to and positioned with fixed coordinates, because .antibody-table-page sets overflow on small screens and would clip a normally-positioned dropdown. Class names are deliberately unlike the homepage's (.search-bar / #oga-dropdown) so the two mounts can never collide. {% endcomment %}
