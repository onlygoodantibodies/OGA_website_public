Installing it before it is on the stores

Chrome has blocked installing extensions from anywhere but the Web Store since 2018, so until our listing is approved there is no one-click install. The route below works today and takes about a minute.

Chrome, Edge or Brave

  1. Download the zip above and unzip it. Keep the folder somewhere permanent: the browser reads it from disk each time it starts, so deleting the folder removes the extension.
  2. Go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Open any paper and look for coloured antibody names.

Chrome shows a "Disable developer mode extensions" prompt on each restart while it is loaded this way. That goes away once we are on the Web Store.

What the colours mean

Results are given per application. An antibody that works on a Western blot may fail in immunofluorescence, so the extension reads the application from the surrounding text and colours the mention for that application. Of the antibodies we have published against TDP-43, two thirds pass in one application and fail in another.

ColourMeaning
Recommended Tested with knockout controls and recommended for the application used here.
Not recommended Tested with knockout controls and did not meet the bar for the application used here. Where the page doesn't say which application, this means it did not meet the bar in any application tested.
Split Passes in some applications and fails in others. Either the paper used it for several applications with a different result in each, or it never said which application it used, so all four assessed are shown. The hover card says which, and lists the results.
Alternatives exist This antibody has not been tested, but its target has. Validated alternatives are available.
Application untested In the dataset, but not tested in the application this page used it for. Antibodies we hold no data on are left unmarked.

It does not watch you read

The dataset is downloaded and stored in your browser, and all matching happens there. No page text, URL or reading history is sent to us or to anyone else. An unpublished or under-review manuscript stays private.

The extension contacts this site for exactly two things: a once-a-day refresh of the validation data, and loading a validation image when you open a card. Neither carries any information about what you are reading.

Where it runs

On journal and preprint sites — Nature, Science, Cell Press, ScienceDirect, Wiley, Springer, PLOS, eLife, Frontiers, MDPI, OUP, bioRxiv, medRxiv, PubMed and PMC among others. Supplier catalogue pages can be switched on in settings, so you see the same results while choosing what to buy.

It reads the HTML full text of a page. A paper opened as a PDF is not annotated.

What it can and cannot tell you

  • It reports what independent testing found. It does not judge the paper.
  • Most antibodies have never been independently tested. Grey means we have no result for the application used here.
  • Which application a reagent was used for is inferred from the surrounding text. Where a page is ambiguous the extension falls back to a whole-antibody summary and says so on the card.
  • Every card links to the knockout-controlled images, the RRID and the published report, so you can check the colour yourself.

  • A colour that looks wrong on an antibody you know.
  • An antibody the paper cites that was left unmarked.
  • A mark on ordinary text that was never a catalogue number.
  • A journal or preprint site where nothing is marked at all.

Say which page you were on and what you expected — get in touch. A store review helps other people find the extension; the specifics reach us faster here.
